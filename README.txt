自动生成 Slug 与操作日志补丁

功能
1. 文章、分类、单页、导师、学生资料、政策文件、科研机构、成果转化的编辑表单不再要求手工填写 Slug。服务端根据英文标题生成规范 URL 标识；中文标题转为无声调拼音；重名时自动追加 -2、-3 等后缀。修改名称/标题时自动重新生成。
2. Strapi REST 内容写入由 Document Service 中间件统一生成 Slug，创建时忽略客户端传入值，避免绕过；特殊标点等无法转写的内容使用 ASCII 类型前缀和短哈希兜底。
3. 后台成功或失败的写操作、已知后台账号的登录尝试都会写入独立审计集合；不保存密码、正文等字段内容，仅保存变更字段名称、操作人、角色、模块、目标、结果、时间、IP 和客户端信息。
4. 操作日志页支持关键字、模块、操作、结果、日期筛选，分页、详情查看和筛选结果 CSV 导出。查询接口只允许超级管理员或获授 logs 模块 view 权限的角色访问，日志没有前端删除/编辑入口。

应用方式
- 按压缩包中的相对路径覆盖/合并到项目根目录。
- 在 backend 目录运行 npm install（新增 pinyin-pro 依赖），再重启 Strapi；Strapi 会根据新增内容类型建表。
- 重启 Next.js 后台，按角色权限配置中 logs 模块的“查看”权限授权相应角色。超级管理员默认有权限。
