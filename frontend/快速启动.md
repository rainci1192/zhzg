# 🚀 快速启动指南（编程小白版）

## 第一步：安装 Node.js

1. 访问 https://nodejs.org/
2. 下载并安装 LTS 版本（推荐 18.x 或更高版本）
3. 安装完成后，打开命令行工具验证：
   ```bash
   node -v
   npm -v
   ```

## 第二步：安装项目依赖

打开命令行（Windows 用 PowerShell 或 CMD），执行：

```bash
cd e:\zgweb\frontend
npm install
```

⏳ 这个过程需要 3-5 分钟，请耐心等待...

## 第三步：启动开发服务器

```bash
npm run dev
```

✅ 看到以下信息表示成功：
```
- Local:        http://localhost:3000
```

## 第四步：在浏览器中查看

打开浏览器，访问：http://localhost:3000

🎉 恭喜！你的网站已经运行起来了！

## 常用命令

```bash
# 启动开发服务器
npm run dev

# 停止服务器
按 Ctrl + C

# 构建生产版本
npm run build

# 启动生产服务器
npm start
```

## 下一步做什么？

### 1. 替换图片
- 将你的图片放到 `public/images/` 文件夹
- 修改组件中的图片路径

### 2. 修改内容
- 新闻内容：`components/home/NewsList.tsx`
- 通知公告：`components/home/NoticeList.tsx`
- 导航菜单：`components/layout/Header.tsx`

### 3. 修改颜色
- 打开 `tailwind.config.ts`
- 修改 `primary` 和 `secondary` 颜色值

## ⚠️ 常见问题

**问题1：npm install 很慢**
解决：使用国内镜像
```bash
npm config set registry https://registry.npmmirror.com
```

**问题2：端口被占用**
解决：换个端口启动
```bash
npm run dev -- -p 3001
```

**问题3：修改代码后没反应**
解决：保存文件后，浏览器会自动刷新（热更新）

## 📞 需要帮助？

遇到问题不要慌：
1. 检查 Node.js 是否正确安装
2. 确保在正确的目录下执行命令
3. 查看命令行的错误提示
4. 重启开发服务器试试
