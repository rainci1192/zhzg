# 文章列表角色权限修复

## 修复内容

- 修复同一角色同一模块存在多条授权记录时只读取第一条的问题；操作权限会对该模块的全部授权记录做合并判断。
- 兼容 Strapi 关系字段的 `data/attributes` 包装和仅返回关系 ID 的格式，必要时按权限模块/动作目录补全名称。
- 文章编辑、删除、提交审核、发布和取消发布都需要角色对应动作权限，并且仅允许发布者处理本人文章；超级管理员拥有全部权限。
- 取消发布检查独立的 `unpublish` 动作，不再借用 `publish` 动作。
- 后端按 `articles` 模块 ID 查询授权记录，并聚合所有该模块授权，保持与角色权限页的授权结果一致。

## 应用

将压缩包中的文件解压到项目根目录并覆盖同路径文件，然后重启 Strapi 和 Next.js 管理后台。若后台保持热更新，请重新登录或刷新页面以加载最新角色权限。
